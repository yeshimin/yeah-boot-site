YeahBoot 基于 Java 21、Spring Boot 3.5 与 Vue 3，集成后台管理、App 服务和常用工程模块，帮助项目快速完成基础搭建。

FUNCTION MODULES

常用模块，
开箱即用。

覆盖后台和服务端开发中的基础功能。项目可以按需使用，也可以在已有结构上继续增加业务模块。

01

系统管理

用户、角色、资源、组织、岗位、字典、地区、日志和系统参数等模块可直接使用。

02

文件与存储

统一抽象本地、MinIO、七牛等实现，覆盖上传、下载、预览、引用保护和安全删除。

03

通知与消息

短信通知、Redis 消息队列和 WebSocket 推送按模块提供，可根据项目需要启用。

04

工程基础能力

统一返回、异常处理、分页 CRUD、Trace ID、接口限流、数据脱敏、逻辑删除和 Excel 导入导出。
