YeahBoot 是一套面向后台管理和 App 场景的开发基础项目。基于 Java 8、Spring Boot 2.7 与 Vue 3，提供认证、权限、系统管理、文件存储和运行时配置等常用能力。

CORE CAPABILITIES

后台项目需要的基础能力，
已经为你整理好。

不追求堆砌概念，优先覆盖真实项目中高频、通用、需要反复建设的部分。

认证与服务端 Token

JWT 签名验证结合 Redis Token 状态，支持主动退出、强制下线、终端与在线数量控制。

登录认证JWTRedis 校验业务接口

清晰的资源权限

视图资源和接口资源分层管理，授权依然保持扁平，兼顾交互清晰和鉴权简单。

完整的系统管理

用户、角色、资源、组织、岗位、字典、日志和系统参数形成可直接使用的管理闭环。

统一文件存储

本地、MinIO、七牛存储统一抽象，覆盖上传、下载、预览、引用标记和安全删除。

运行时系统参数

业务参数由数据库维护并缓存到 Redis，支持默认值、自动刷新和手动重新加载。

工程化基础设施

统一异常、接口日志、Trace ID、限流、数据脱敏、逻辑删除和 Excel 导入导出。

ARCHITECTURE

模块有边界，代码有去处。

启动工程、业务模块、通用数据和基础框架各司其职。你可以完整使用，也可以按项目需要裁剪。
